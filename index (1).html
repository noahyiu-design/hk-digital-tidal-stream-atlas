Why I made this

Before a race, there is rarely much time to figure out the tide.

As a sailor, I wanted a quicker way to turn tidal predictions into something useful on a race day. Current can influence where boats line up, how they approach marks, which side of the course is worth considering, and when a maneuver needs to happen.

Traditional tidal-stream information can be hard to read quickly. This project puts it on an interactive map, so users can see how the current changes from place to place and over time.

How I built it

From raw tide data to a map you can use.

I used ArcGIS Pro to prepare the data and build the visual system, then published the finished map through ArcGIS Online.

01

Download the tidal data

Published tidal prediction data were downloaded from the Hong Kong Tidal Stream Prediction System.

02

Clean and reshape the dataset

The data were cleaned and unpivoted so they could be used properly in ArcGIS Pro.

03

Bring the data into ArcGIS Pro

The prepared dataset was imported into ArcGIS Pro for mapping and further processing.

04

Turn the records into map vectors

The dataset was converted into mapped vector features, allowing each tidal observation to be placed on the map.

05

Add the time frame

A Time Frame field was added so the map could show the progressive change in tides at 15-minute intervals.

06

Set up the visual language

Symbology was configured to show current direction and current speed visually: color represents direction in degrees, and arrow size represents speed in knots.

07

Publish the interactive map

The project was published to ArcGIS Online as an interactive web map with a time slider, legend, and clickable vector details.

What comes next

This is a planning tool, not a full real-time forecast—yet.

The current version is based on tidal predictions. It does not yet include short-term weather effects, such as wind-driven changes in current or a weather-adjusted 96-hour layer. I would like to build in those factors, create race-venue views, and add tools that make pre-race use even quicker.
